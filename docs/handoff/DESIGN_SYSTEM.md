## 2. สีที่มีความหมายตายตัว (ทุกเลนใช้เหมือนกัน)

| ความหมาย | ใช้เมื่อ |
|---|---|
| success / เขียว | ทำสำเร็จ · สถานะปกติ · มาเรียน |
| warning / เหลือง-ส้ม | ต้องระวัง · รอดำเนินการ · มาสาย |
| danger / แดง | ล้มเหลว · เหตุฉุกเฉิน · ขาดเรียน · ระงับบัญชี |

ทุก palette มี `success` / `warning` / `danger` (หรือ `green`/`yellow`/`red`) อยู่แล้ว
**ห้ามเขียนสีแดงดิบเพื่อสื่อ error** ให้ใช้ค่าจาก palette ของเลนนั้น

## 3. กติกา — สิ่งที่ทำให้ drift หยุดขยาย

1. **ห้ามฮาร์ดโค้ด `Color(0xFF...)` ในไฟล์หน้า** ให้เพิ่มค่าเข้า palette ของเลนแล้วอ้างชื่อ
   หนี้ปัจจุบัน (2026-09-10): Teacher 1,222 · School Admin 953 · Student 437 ·
   Executive 412 · Parent 306 · Super Admin 60 รวม **3,390 จุด**
   ไม่ต้องไล่แก้ทั้งหมด แต่**อย่าเพิ่มจุดใหม่**
2. **หนึ่งเลน = หนึ่งไฟล์ palette** วางไว้ใน `<lane>/theme/`
   (เคยมี `school_admin_palette.dart` ซ้ำ 2 ไฟล์เนื้อหาเหมือนกันเป๊ะ
   แก้สีทีต้องแก้ 2 ที่ ไม่งั้นเพี้ยน — รวมเป็นไฟล์เดียวแล้ว 2026-09-10)
3. **ห้ามสร้างช่องกรอก/ปุ่มที่หลังบ้านไม่รองรับ** ถ้าอ่านค่าได้แต่เขียนกลับไม่ได้
   ให้แสดงแบบอ่านอย่างเดียวพร้อมบอกว่าแก้ที่ไหน (ดูตัวอย่าง `_ReadOnlyField`
   ใน `school_permissions_page.dart`) — กติกาเดียวกับ DATA_CONNECTION_METHODOLOGY.md
4. **ข้อมูลจำลองต้องติดป้าย** ถ้ายังไม่มีหลังบ้านและจำเป็นต้องโชว์ ให้ติด
   badge "ข้อมูลจำลอง" ให้ผู้ใช้เห็น ไม่ใช่ปล่อยให้เข้าใจว่าเป็นของจริง

## 4. ค่ามาตรฐานของหน้าจอ

**มือถือ (ตั้งแต่ 2026-09-18 — เจ้าของตัดสินใจ "ทำตามกติกา Apple")**
- Status bar เป็นของระบบ **ห้ามตัด/ทับ** (เคยตัด 12pt ให้ชิด Dynamic Island แล้วถอดออก)
- Navigation bar สูง **44** (`toolbarHeight: 44`) ไม่ใช่ 56 ของ Material
- ระยะขอบซ้าย-ขวา **16** ทุกความกว้าง (หน้าแรก/ปฏิทินเคยใช้ 12 บนมือถือ — แก้แล้ว)
- Tab bar ใช้ `BottomNavigationBar` มาตรฐาน + safe area ระบบ
- Grid 4 คอลัมน์/gutter 16 เป็นแนวทางนักออกแบบ ไม่ใช่กติกา iOS — ชิป 4 ช่องใช้ gutter 8 ได้
- เทสต์ layout มือถือ (`test/iphone_layout_test.dart`) pump ที่ **360×640 / 375×667 / 390×844** ทุกเคส — ครอบ Android ทั่วไป, iPhone SE/8, iPhone 14–16 · เทสต์อื่น pump 900–1200px จะไม่เจอปัญหามือถือ · จุดตัด: <430 = มือถือ (1 คอลัมน์/ชิป 4 ช่อง) · 430–899 = แท็บเล็ตแนวตั้ง (grid 2 คอลัมน์) · ≥900 = เดสก์ท็อป 2 คอลัมน์


**รายการบนมือถือ = "กล่องเดียว หลายแถว" (ใช้ในหน้ารายละเอียดวิชาของครู ตั้งแต่ 2026-09-21)**

แท็บ `ใบงาน` / `นักเรียน` / `คะแนน` ใช้รูปแบบเดียวกันทั้งหมด:

- กล่องขาวใบเดียว มุมโค้ง **14** เส้นขอบ 1px `TeacherPalette.border`
  ข้างในเป็นแถวคั่นด้วย `Divider(height: 1, indent: 56)` — **ไม่ใช่การ์ดใบละแถว
  ที่มีเงาและ margin 12** (แบบเดิมกินความสูงเกือบเท่าตัวโดยไม่เพิ่มข้อมูล)
- แถวหนึ่ง = วงกลมอักษรแรก 34pt · ชื่อ 15/`w800` · เมตาเงียบ 1 บรรทัด 12/muted ·
  ของท้ายแถว (คะแนน/สถานะ) ถ้ามี — ทุกบรรทัด `maxLines: 1` + ellipsis
- **ค่าที่เหมือนกันทุกแถวห้ามแปะทุกแถว** ให้บอกครั้งเดียวที่หัวแท็บ
  (ป้าย "เรียนปกติ (Active)" และป้ายห้องของวิชา ถูกถอดออกด้วยเหตุนี้)
- ตัวกรองเป็น `_FilterPill` แถวเดียว `Wrap` ได้ · ปุ่มหลักอยู่ท้ายแถวตัวกรอง
- แตะแถวแล้วเปิด action sheet แทนปุ่ม 2 ปุ่มในทุกแถว —
  **ถ้าไม่มีปลายทางจริง ห้ามทำให้แถวดูกดได้** (แท็บนักเรียนจึงไม่มี chevron)
- `DataTable` ใช้ได้เฉพาะ ≥700pt · ต่ำกว่านั้นให้เปลี่ยนเป็นรายการแบบข้างบน
  (ตารางคะแนน 5 คอลัมน์กว้างราว 720pt ต้องเลื่อนแนวนอนกว่าจะเห็นคะแนน)
- การ์ดสรุปบนมือถือใช้ `_MiniStat` แถวเดียว (label 11 + ตัวเลข 15/`w900`)
  คำอธิบายใต้ตัวเลขเก็บไว้เฉพาะเดสก์ท็อป

อ้างจากที่ใช้จริงซ้ำ ๆ ทั้งแอป:

- **มุมโค้ง**: การ์ด 16–20 · ช่องกรอก/ปุ่ม 14–16 · ชิป/badge 999 (เต็มวง)
- **ระยะห่าง**: 6 / 8 / 12 / 16 / 18 / 22 / 24 (คูณ 2 ตลอด)
- **ฟอนต์**: `Noto Sans Thai Looped` — ไทย **มีหัว** ฝังมากับแอป 6 น้ำหนัก
  (2026-09-22 เปลี่ยนจาก `Noto Sans Thai` ที่ไม่มีหัว) ตั้งที่เดียวใน
  `app_theme.dart` · `role_theme.dart` · `super_admin/theme/app_palette.dart`
  **ห้ามเรียก `GoogleFonts.*()` ในหน้าใด ๆ** — runtime fetching ปิดอยู่
  (`main.dart`) ขอฟอนต์ที่ไม่ได้ bundle = ข้อความไทยหายทั้งหน้าโดยไม่มี error
  ล็อกไว้แล้วใน `test/bundled_fonts_test.dart`
- **ขนาดตัวอักษร**: หัวไดอะล็อก 20 · หัวการ์ด 16 · เนื้อหา 13–14 · label 12–12.5 · หมายเหตุ 11.5
  ⚠️ ของจริงในโค้ดใช้อยู่ **63 ขนาด** (เลนครูลานเดียว 35 ขนาด ตั้งแต่ 8.5 ถึง 42
  รวมครึ่งหน่วย 1,195 จุดทั้งแอป) — สเกลด้านบนเป็นเป้า ไม่ใช่สภาพจริง
  ยังไม่มีใครบังคับใช้ ดูข้อ 6
- **น้ำหนัก**: หัวข้อ `w800`–`w900` · เนื้อหาเน้น `w700` · ปกติ default
- **เส้นขอบ**: 1px สีอ่อน (`border` ใน palette) ไม่ใช้เงาหนัก
- **จุดตัด responsive**: 2 คอลัมน์ที่ ≥940px (ใช้ในหน้า login) · sidebar ยุบที่ <1100px

## 5. ภาษา

- **UI เป็นภาษาไทยทั้งหมด** ห้ามปนอังกฤษในข้อความที่ผู้ใช้เห็น
  (หน้า login เคยมี "Welcome back" / "Login" / "Username" ปนอยู่ — ล็อกด้วยเทสต์แล้วใน
  `test/login_page_redesign_test.dart`)
- ยกเว้นรหัสอุปกรณ์/รหัสวิชาที่เป็นรหัสจริง เช่น `CAM-B1-01`, `STU002`
- **ห้ามโยนข้อความ exception ดิบ (`$e`) ขึ้นจอ** ให้ข้อความคงที่ที่ผู้ใช้อ่านรู้เรื่อง
  แล้ว `debugPrint` ตัวจริงไว้ดูเอง
  หนี้ปัจจุบัน: Teacher 37 จุด · Super Admin 23 (ส่วนใหญ่เป็นหน้า diagnostic
  ที่ตั้งใจโชว์) · Executive 7 · School Admin 5 · Student 4 · Parent 4
